# walrus Landing (Next.js)

Premium marketing landing page for **walrus**.

Tagline: **A real-time signal layer for breaking news.**

## Tech

- Next.js (App Router)
- React + TypeScript
- TailwindCSS
- Framer Motion
- tsParticles

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Rename product quickly

Update `PRODUCT_NAME` and `TAGLINE` in [app/page.tsx](./app/page.tsx).
